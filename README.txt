ながめるカレンダー v2.1
========================

【今回の追加機能】
・設定画面の案内を日本語に統一
・中央競馬GⅠ＋障害J・GⅠ、および地方競馬GⅠ・JpnⅠの開催日を表示
・中央競馬、地方競馬の表示・非表示は設定から個別に切替可能
・日付をタップすると複数レースを一覧表示（個人の予定に登録せず表示）
・2028年以降の祝日を内閣府CSVの更新後に自動取得できる仕組み
・競馬の将来の日程も、公式の公開ページを利用して更新を試みる仕組み
・ネットがなくても収録済みの2025～2027年の祝日と2026年のレースを表示

【重要：既存の予定は消えません】
・localStorageのキーはv1から変更していません（nagame-calendar-v1）。
・同じGitHub PagesのURLで上書き更新すれば通常は既存の予定を引き継ぎます。
・ただし、更新前に「設定」→「バックアップを保存」を推奨します。
・別リポジトリや別URLに引っ越すと、予定データは自動で引き継がれません。
・予定はiPhone内のSafari／ホーム画面アプリに保存されます。GitHubにはアップロードされません。

【GitHub Pagesでの初回公開方法（祝日・競馬の自動更新も含む）】
1. ZIPをMacで解凍。
2. GitHubのPublicリポジトリを作成（例：nagame-calendar）。既存のものを更新するならそのリポジトリを開く。
3. ファイルとフォルダをリポジトリの一番上にアップロードする。
   必要なもの：index.html / app.js / styles.css / holidays.js / races.js / sw.js
   manifest.webmanifest / icon-192.png / icon-512.png / data/ / scripts/ / .github/
   注意：Macで「.github」が見えない場合は、Finderで Command + Shift + . を押して隠しファイルを表示。
   .github/workflows/official-calendar-update.yml を含めることが必須。
4. GitHubのリポジトリの「Settings」→「Pages」を開き、
   「Build and deployment」→「Source」で「GitHub Actions」を選択する。
5. リポジトリの「Actions」を開き、必要ならワークフローを有効化する。
   「カレンダー公開・祝日とG1競馬の自動更新」が実行されれば公開まで行う。
   実行されていなければ「Run workflow（ワークフローを実行）」から手動で一度起動。
6. 「Settings」→「Pages」に出るURLをiPhone Safariで開く。
7. Safari共有メニューから「ホーム画面に追加」でアプリとして使用する。

【自動更新の仕組みと制限】
・GitHub Actionsが毎日午前3時（日本時間）に公式ページを取得し、更新がある場合に公開データを置き換えます。
・祝日の取得元：内閣府公開CSV（1955年～公表済み年）。まだ正式発表のない年は推測しません。
・中央競馬の取得元：JRA公式「GⅠレース一覧」。
・地方競馬の取得元：地方競馬情報サイト「GI/JpnI競走プレレーティング」。
・JRAの将来のGⅠ一覧および地方競馬の翌年の正式な一覧が未公開なら、未公表の日程は表示しません。
・取得失敗や公式ページの構造変更時は、既存の正しい日程を維持し、推測で補いません。
・公式の日程変更があった場合、GitHubでの自動更新に成功して次にアプリがオンラインで開かれた際に反映されます。
・GitHub Actionsはリポジトリの無活動や利用上限・設定変更などで停止する場合があります。
  「Actions」で自動更新が継続しているか時々確認してください。
・自動更新を利用しない場合もアプリは使えますが、2028年以降の祝日を自動で追加できません。
・GitHub Pagesを「Deploy from a branch」ではなく「GitHub Actions」に設定してください。

【操作】
・上下にスクロールして月移動。日付タップで予定登録またはレース詳細表示。
・「いつもの予定」で1タップ追加。自分の予定は色分け・繰り返し登録可。
・設定の「中央競馬GⅠ」「地方競馬GⅠ・JpnⅠ」チェックで表示切替。
・設定の「今すぐ日程を確認」でGitHub上の最新公開データを再読み込み。
・設定の「バックアップを保存」でJSON形式に保存。必要に応じて読み込み。

【v2.1 不具合修正】
・地方競馬の自動取得処理が「開催場」と「競走名」を取り違える不具合を修正。
・表の列名から解析位置を確認し、誤った表を読み込んだ場合は更新しません。
・オンラインで公開ファイルが更新されても古い画面が残るキャッシュ問題を修正。
・中央/地方の片方の開催日だけを更新しても、もう片方を消さないよう変更。
・古い公開データで、より新しい端末内キャッシュを上書きしないよう変更。
・公式祝日の日付訂正がある場合は、該当年単位で置き換えるよう変更。
・自動更新の実サイト接続・GitHub Actions定期実行は、公開環境での追加確認が必要です。
